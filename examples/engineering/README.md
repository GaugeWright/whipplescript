# The engineering vocabulary

One organization's software-engineering process as a norm-plane charter
(DR-0123). Install it into a fresh ledger:

```sh
whip norm bootstrap --as <binding> --creator <principal> --charter examples/engineering/charter.json
```

Every noun is a profile of a bundled noun — `requirement` of `obligation`,
`initiative` and `task` of `issue`, `specification` of `manifest`,
`observation` of `assertion` — and every edge is a relation declaration:
`incorporates` is the accepting authority's attestation that a decision's
intent appears in an exact requirement revision, `targets` names the exact
revision a task addresses, `supports` offers an observation for one, and
`baselined_on` and `supported_by` bind a release to its baseline and its
evidence. Each edge binds its family basis and its references as premises,
so a replay reproduces every admission.

The kernel interprets nothing here that it does not interpret for the
bundled defaults. A different process is a different charter.
