# Tutorials

These are three guided builds. You can run each build from end to end on the
deterministic fixture provider. You do not need credentials. Do the builds in
sequence the first time:

| # | Tutorial | You build | You learn |
| --- | --- | --- | --- |
| 1 | [Run a root agent](root-agent.md) | an agent loop that an operator drives | messages as turns, governed authority, how to observe the record |
| 2 | [Build a workflow](build-a-workflow.md) | a triage pipeline with a gate for a person | facts, rules, effects, trackers, terminals |
| 3 | [Govern a workflow](governance.md) | a signed envelope for information flow | labels, denials, crossings, the guarantee report |

If you have run nothing before, start with the [quickstart](../quickstart.md).
The quickstart is a tour of five minutes. The tutorials give you a feel for the
language. The [manual](../manual.md) then teaches the full language.
